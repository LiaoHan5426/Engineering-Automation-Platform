CAPABILITIES

          
能力目录

          
按执行方式分成四类，每类都有自己的管理入口：内置命令在运行时内执行，本地 CLI 需要二进制存在，MCP 工具来自显式信任的服务器，HTTP 服务尚未接入。目录来自运行时与处理器声明，而不是专家定义里的名字清单。

          

            每类能改什么由后端声明，界面不自行推测：内置命令只能启用/停用，本地 CLI 还能指定二进制位置，MCP 工具的服务器由操作者登记。
            新增能力一律需要改代码——发布哪些事实属于代码契约，不能由一次界面操作产生。

MCP 工具 mcp 专家级

              
由 MCP 服务器发布的工具：不是平台能力，不会全局启用。必须由专家清单声明、启用时授权，并只在该专家本次执行的会话内调用。

            

            0 项
          

          

            
这里可以改什么：登记、修改、启用、信任、放行工具与删除服务器。

            
能力本身是怎么来的：服务器由外部提供，平台记录它的位置与工具白名单，再由专家逐工具声明授权。平台既不替服务器创建工具，也不把服务器返回的内容当作已验证事实。

          


          
一个完整示例

          
下面是「登记完成之后长什么样」的示例，不是已登记的数据：它演示字段怎么填、会发布出哪些能力标识，以及还差哪一步才能真正被调用。

          

            

              本地文件检索 files
                示例 未启用 未信任
              
            

            

              
传输方式
stdio（本机进程）

              
启动命令
npx -y @modelcontextprotocol/server-filesystem

              
工具白名单
search、read（操作者声明，未经协议验证）

              
发布的能力
mcp.files.search、mcp.files.read

              
还差什么
两步：① 启用并信任这个服务器；② 在专家清单的 mcpTools 里逐条声明工具。只登记不启用，能力目录里不会多出任何东西——这正是「不会全局启用」的含义。

            

          


          
登记 MCP 服务器

          
服务器由外部提供，平台只记录位置与工具白名单。登记不等于启用：默认不启用、不信任。地址里不要放 Token 或密钥，凭据请用环境变量注入。

          

            
            
            
          

          

            
            
            
            
            
          

          
服务器标识与工具名都会拼进能力标识 mcp.<服务器>.<工具>，因此只允许小写字母、数字、下划线和连字符；不合法会在登记时当场拒绝，而不是等到专家引用时才报错。

          


          
已登记的服务器

          

          

            尚未登记
            当前 0 个服务器。没有服务器就没有可授权的专家级能力——也不会退化为“全部允许”：登记表读不到时返回零工具，而不是全部放行。
          

          
启用与信任是两件事，只有同时成立才可用；撤回信任、停用或删除已被已启用专家授权使用的服务器会被拒绝并点名专家。原型里这份授权表是空的——没有任何专家在清单中声明过 MCP 工具，所以这里不会出现拒绝；规则本身写在后端。


          

            为什么不能全局启用
            
              一个 MCP 会话绑定着会话标识、游标与已认证身份。若平台把工具注册成对所有专家生效，两个专家就会共用同一会话：
              B 的调用可能落在 A 的状态与授权上下文里，A 留下的半消费游标还会让 B 漏读数据，审计也无法区分是谁发起的。
              因此工具能力按 mcp.<服务器>.<工具> 命名，会话按
              (执行, 专家, 服务器) 三元组隔离，执行结束即关闭。
            
          


          
由服务器发布的能力

          

          
还没有任何服务器发布工具，因此没有专家级能力。登记服务器后，它的每个工具都会出现在这里，并如实标注「尚未接入」：平台尚无 MCP 客户端，白名单是操作者声明，节点暂时无法执行。
