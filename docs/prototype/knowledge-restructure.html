知识库

知识库只是文本容器；授权发生在专家启用时。点一行进入它的文档。

检索范围 已启用专家被授权的知识库：—。未授权的知识库不出现在结果里；没有命中时返回零结果并说明原因，而不是放宽到全部知识库。

跨知识库检索

这是一个独立工作面：它的范围跨库，因此不再挤在某个知识库卡片内部。

输入关键词后回车或点「检索」。结果会标明来源引用，点击即在「文档」页签打开。

三类形态为什么这样分工

主骨架二级页面（页签）

用于「目的地」：内容体量大、需要互相切换、并且应当能被链接到。

  • 知识库 / 文档 / 检索 三个工作面平级
  • 页签是状态，可断言、可深链、可回归
  • 与能力目录、桌面外壳的做法一致
不用于：一次性事务——那会造出一个只为一次提交而存在的空页面。

动作抽屉

用于「附着在当前上下文上的一次动作」，需要主内容保持可见以作对照。

  • 新建知识库 / 重命名 / 新增文档
  • 关闭时带「未保存」拦截，与专家工作室的草稿状态对齐
  • 提交后留在原处，列表可见且新行被高亮
不用于：主导航——抽屉关掉就没了，也拿不到深链。

阻断模态确认

用于「必须先处理完才能继续」的动作，尤其是破坏性的。

  • 删除知识库 / 删除文档
  • 确认正文直接写出影响面：几篇文档、被哪些已启用专家引用
  • 原生 <dialog>，自带焦点陷阱与 Esc
不用于：浏览或编辑——那会变成反复开关的弹窗地狱。
