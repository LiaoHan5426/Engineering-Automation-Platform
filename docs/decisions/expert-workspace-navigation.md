# 专家工作区与独立编辑工作台

状态：固定流程、SQL Agent、GrapesJS共用三栏工作台已实施，纳入 `2c7e87b` 并推送。本文维护当前交互与复用边界；[完整演进记录](../records/frontend-history.md#expert-workspace-evolution)保留截图反馈、旧方案、验证命令与失败修复。技术检查通过不等于用户最终接受。

## 管理、执行与编辑分开

| 入口 | 职责与返回关系 |
|---|---|
| `#experts` | 我的专家：搜索、类型/启用状态、创建固定流程或SQL Agent |
| `view=overview&expert=…` | 专家概览；开始任务与“编辑专家”分别进入执行页和独立编辑工作台 |
| `view=config&expert=…` | 兼容原配置深链；同一标签内独立编辑，收起管理侧栏，明确返回专家详情 |
| `view=tasks` | 全部任务；带expert时按专家筛选，服务端最近100条，不宣称全历史分页 |
| `view=start` | 当前SQL Agent的任务输入与费用确认；未提交输入需要处理后才离开 |
| `view=task&expert=…&run=…` | 目标→结果与待办→参考资料；完整输入、引用摘录、取证记录和运行元数据按需打开右侧Drawer |
| `view=review` | 候选Diff、绑定摘要与审批；终态仅展示记录，awaiting-approval才允许批准/拒绝 |

URL支持直接打开、刷新和历史导航。父级返回保留列表搜索、任务筛选与滚动；来源会话返回保留。全局任务及其详情/审阅归属“全部任务”，单专家任务归属“我的专家”，侧栏互斥选中。对话角色是消息指引，不等同可执行专家。固定流程继续进入原SQL分析工作台，不虚构后台DAG历史。

独立工作台是应用内全工作区路由，当前没有新开操作系统窗口或提供多标签并发编辑。浏览器后退、跨区域离开和刷新保留未保存保护。

## 三栏编辑合同

| 区域 | 固定流程 | SQL自主Agent | 原型设计器 |
|---|---|---|---|
| 顶栏 | 返回、名称、校验、保存；启用授权另行确认 | 相同草稿/授权边界 | 返回、文档名、预览、保存版本 |
| 左栏 | 可搜索节点库 / 流程结构树 | 受支持工具与资料引用 | 组件库 / 页面结构树 |
| 中区 | WorkflowCanvas：拖动、端口连线、拒绝循环、自动布局、全图与缩放 | 目标与专业行为配置；不渲染虚构DAG | GrapesJS画布与语义预览 |
| 右栏 | 专家设置 / 所选节点属性 | 基本信息、资料、规则等分类设置 | 页面设置 / 所选组件文本、布局与间距 |
| 按需问题区 | 校验问题与节点/字段定位 | 行为及字段校验 | 未知映射/Schema问题定位 |

节点通过资源卡片显式添加，添加后选中；结构树、画布和属性共用选择状态。删除节点或撤销工具声明清理关联连线。目录失败明确报错，不用硬编码列表虚构可用能力。左右栏可调整、折叠及独立滚动；窄容器改用Drawer，保留焦点/Esc和画布挂载，页面不横向溢出。

保存草稿沿用后端停用/撤权规则，重新启用需要确认。内置模板先复制；已保存标识不直接改名；未知行为版本拒绝编辑。SQL Agent保存为 `sql-readonly-agent/v1`，steps/edges为空，预算仍由服务端控制。加入资源引用不等于授予执行权限。

原型保留Grapes工程与语义Schema双数据、本地保存重开及既有版本/交付链。预览使用真实Vue交互；未知映射阻止后续发布。退出、切页、新建和重开前处理脏草稿。共享布局不会自动扩大组件/动作映射或源码交付能力。

## 任务阅读与刷新

终态停止自动轮询，保留手动刷新；活动任务后台更新不插入反复出现的加载文字，未变化的数据不替换详情对象。首次加载与失败有独立提示，列表刷新不加载隐藏详情。离开页面不取消服务端任务，待审批继续保留到期与绑定校验。

右侧详情只读取当前任务已保存内容；引用摘录不冒充当前文档全文。切换任务清理旧面板，Esc关闭后焦点返回触发按钮。审批仍在独立审阅页，辅助详情不能触发写操作。当前专家停用不覆盖历史任务状态。

## 共享组件边界

`@eap/ui` 的 `EditorWorkbench` 位于 `packages/ui/src/layout`，只提供槽位、分栏、折叠、滚动和响应式布局，复用Splitter/Drawer；领域继续复用Tabs、Tree、Panel、Button等公共组件。它不持有Expert、Capability、Schema、审批/API或保存状态机。

ExpertEditor、WorkflowCanvas及专家任务侧面板归专家领域；GrapesJS、Schema及版本归原型领域。保留现有两种文档模型，没有建立第二套能力目录、通用插件SDK或空layout包。详见[共享模块落点](frontend-ui-shared-module-boundaries.md)。
