# 前端交互恢复与草稿归属（2026-11-14集中修复）

状态：本轮集中修复决策；实现、验证和保留边界见[逐页审计](../evidence/frontend-batch/README.md)。沿用现有Vue/公共UI/feature状态，不更改后端接口、领域状态集、授权或UNKNOWN处理。当前工作项状态仍只由[规划台账](../planning-status.md)维护。

## 草稿与离开

- 模型目录、MCP登记、新建知识库、看板普通创建/原型选择、交付文本等未提交编辑，复用公共ConfirmBox。取消继续编辑，确认才丢弃；保存中阻止关闭与重复提交。未改动不增加确认。
- ModelSettings和ProjectBoard将局部guardLeave暴露给App，固定入口与hash导航使用同一个业务守卫；明确放弃后继续原目标导航。App不承载领域API或草稿数据。
- KeepAlive管理页面离开时，公共Dialog/ConfirmBox隐藏其Teleport子树并保留组件实例/输入，返回时重新聚焦。CLI能力Tab切换也保留草稿并隐藏其表单；禁止弹窗残留遮挡其他工作面。
- 聊天未发送草稿保持原会话/草稿身份，不因进入历史或新会话丢失；异步文件读取与新会话创建只允许写回发起时仍有效的上下文。
- 输入密钥不新增草稿持久化。模型连接先前的清空/确认规则仍遵循[连接合同](model-catalog-and-chat-selection.md)。

## 异步完成的归属

规则包选择/试算、交付候选状态、会话创建和附件读取继续使用feature拥有的请求代次或稳定身份；过期成功和失败均不能污染当前选择。没有新增全局请求注册表或把消息文本作为业务分支。

保存完成只确认实际提交的快照，不能把请求期间的新编辑标成已保存。规则包读回保留新修改和当前子页；尚未应用的JSON草稿单独保留并计入脏状态，要求明确应用后再校验/保存/试算。专家编辑保存期间锁定字段/动作并用已提交身份回到结果，防止草稿身份改变影响完成事件。

连接、知识库创建及文档录入的写入成功与后续读取失败分别处理：已接受的保存先清空/结束编辑并保留服务器身份，再读回；刷新失败明确提示已保存并只提供GET重试，防止重复创建。连接全部字段在保存期间锁定。MCP保存错误必须位于当前弹窗内。看板详情的错误同时在详情内部可见，不仅留在遮罩后的列表。

## 加载、错误与持久化

数据库资料/知识列表/专家初始化明确区分加载、失败及成功空列表，并提供原位重试；不把失败渲染成没有数据。Builder切换版本/重试清除上一操作的错误，保持失败恢复的一致身份。SSR构造原型作用域存储时不直接求值浏览器localStorage；真正读写无存储时仍抛出既有拒绝语义，不以内存假保存掩盖持久化失败。

## 实现落点

现有公共Dialog/ConfirmBox及暂存hooks处理无领域生命周期；页面草稿、请求代次、提示和业务编排继续留各feature。公共网络/API合同保持原位置。已搜索现有原语、按层复用，无新共享包或组件平行壳；边界/架构及相关行为回归必须通过。

本决策不升级历史PB-01生成页面验收，不改已存在的持久请求/UNKNOWN联锁，不将受控HTTP夹具当真实后端落库。完整辅助技术/原生缩放、真实供应商与用户接受另验。
