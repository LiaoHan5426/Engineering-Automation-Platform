# 桌面工作台初步调整

日期：2026-10-26。范围：五入口导航、对话输入操作、原型到代码场景。复用当前 Vue Renderer；未交付 Electron。

## 信息结构

- 活动栏固定为 code · 编程、work · 办公、场景、专家、设置。
- 编程包含工程对话及分析工作台；会话列表继续由已有工作区管理。
- 场景提供“原型 → 代码开发”：原型编辑、交互预览与版本保存、引用版本进入代码对话。
- 专家独立呈现；模型、插件、规则、知识、数据库及能力管理归设置。
- Builder 两个实例继续使用已有配置及版本存储。禁用插件后场景操作不可用，仍可到插件中心启用。
- 办公明确为待接入空态，不模拟业务执行。

## 输入框

模式、写入策略、模型和推理强度直接出现在操作栏；引用及指令仍按需展开。模型管理入口返回设置。保留既有切换连接确认及写入确认。

连接与模型目录已拆开，允许列表和会话模型选择已接入。旧单模型字段不作为兼容入口；具体接口、能力边界及验证说明见 [模型目录与会话选择](model-catalog-and-chat-selection.md)。ChatGPT 账号登录实现见 [账号登录](chatgpt-account-sign-in.md)，真实账号授权与模型调用仍需单独验收。

## 后续交互收口

- 五入口切换记住本次页面生命周期内各分区最后访问的页面；直接打开办公页也能正确高亮。原页面插件禁用时回退到当前可用入口。
- 场景页读取两个 Builder 实例的已保存版本。必须显式选择版本才能进入编程对话，沿用版本 ID 引用协议，不自动发送消息。列表失败时阻止交接并显示错误，提供刷新入口。
- 登录设置页重新挂载时查询保存的授权尝试，即使链接已过期也检查可能已完成的授权。已保存链接仅允许官方授权地址；无模型权限的账号也可断开连接。
- 聊天、原型 A、原型 B 首次访问后保留组件实例，切换到其他区域只隐藏。三个工作区各自保存内存状态，避免跨区域切换销毁未保存草稿或正在等待的对话。缓存最多三个工作区；禁用对应插件或关闭应用时释放，不宣称刷新后恢复未保存编辑内容。
- 聊天重新显示时刷新模型连接及服务状态，场景传入的原型版本在工作区显示且可编辑时消费一次；发送中保留待交接版本，待请求结束后再应用，不自动发送。收起输入框弹层以免返回时残留旧菜单。
- 生命周期测试以组件替身验证实例保留、独立草稿、隐藏时异步响应完成和插件禁用释放；输入框测试验证隐藏/发送期间交接延后及单次消费。真实模型调用、浏览器编辑器布局及跨刷新恢复不在这些测试证据范围内。

## 人工验收

1. 逐个点击五入口，检查对应侧栏及已有设置可达。
2. 从场景打开原型 A，手工编辑并测试预览按钮，保存版本后引用到对话；确认未自动发送或执行。
3. 检查原型 B 配置独立，插件禁用后入口与场景状态一致。
4. 输入草稿，切换模式、写入策略与支持的推理强度，核对实际请求；切换连接继续要求确认目标。
5. 检查小窗口操作栏换行、独立滚动及弹层可达性。

界面和模拟边界需人工验收；构建、单元测试与 HTTP 成功均不替代真实模型和业务验收。
