## 优先级审计与实施范围

| 优先级 | 当前问题及影响 | 本轮处理 |
|---|---|---|
| P0 | 发送中全局黄色提示与assistant等待提示重复，归属不清 | 当前会话内显示轮次状态；离开聊天时仅保留可返回的会话运行提示 |

| P0 | 网页搜索/读取/启用复选框标签只传入不消费slot的组件 | 显式label关联，授权含义可见且有无障碍名称 |
| P1 | 计数遗漏本地附件，源文件预算被误当全部上下文数 | 区分本地附件、仓库引用与其他上下文，不伪造token统计 |
